## 开源与设计致谢 🙌

本站基于现代 Web 开源生态构建与定制，在此向以下开源项目及创作者致以诚挚感谢：

- **站点模板灵感**

  本站的交互布局与动态强调色设计最初复刻并演进自开源项目 [enji.dev](https://github.com/enjidev/enji.dev)（MIT License），感谢原作者 Enji Kusnadi 在前端细节与阅读体验上的精彩探索，以及 [Theodorus Clarence](https://theodorusclarence.com/) 在文章多表情互动机制上的启发。

- **核心技术框架**

  感谢 [Next.js](https://nextjs.org/)、[React](https://react.dev/)、[Tailwind CSS](https://tailwindcss.com/)、[Framer Motion](https://www.framer.com/motion/)、[Prisma](https://www.prisma.io/) 与 [MDX](https://mdxjs.com/) 团队提供的高效开发体验。

- **图标与字体资源**

  感谢微软开源的 [Fluent Emoji](https://github.com/microsoft/fluentui-emoji)，以及 Google Fonts 提供的 **Plus Jakarta Sans**、**Noto Sans SC** 与 **JetBrains Mono** 字体家族。
