## 硬件与桌面环境

日常采用 **macOS 笔记本 + 4K 外接显示器** 的双屏开发布局：主屏专注编写后端与 Agent 核心代码，副屏常驻终端日志流、接口调试面板或浏览器实时预览，减少频繁使用 <span className="text-xs"><Kbd>Cmd</Kbd> + <Kbd>Tab</Kbd></span> 切换上下文的心智损耗。

| 设备类别   | 配置说明                                                  |
| ---------- | --------------------------------------------------------- |
| 主力开发机 | Apple Silicon Mac（macOS · 统一内存架构，多容器流畅并行） |
| 外接显示器 | 27 英寸 4K IPS 显示器（高像素密度阅读长代码与日志更舒适） |
| 输入外设   | 机械键盘（线性轴体）+ 人体工学无线鼠标                    |
| 音频设备   | 主动降噪耳机（保障深度编码与架构设计时的专注度）          |

## 核心开发与排障工具链

针对全栈与 AI 工程的多语言协作场景，我将工具链按职责划分为四个高频组合：

### IDE 与代码编辑

| 工具名称         | 主要用途                                                       |
| ---------------- | -------------------------------------------------------------- |
| IntelliJ IDEA    | Java、Spring Boot / Cloud、Flowable 及 Groovy 规则脚本主力 IDE |
| VS Code          | Python 解析脚本、React / Vue / Next.js 前端工程与 MDX 写作     |
| Git & GitHub CLI | 分支管理、Code Review 与提交历史追溯                           |

### 数据库、缓存与中间件调试

| 工具名称                      | 主要用途                                             |
| ----------------------------- | ---------------------------------------------------- |
| DataGrip / Navicat            | MySQL 执行计划（`EXPLAIN`）分析、索引调优与数据核对  |
| Another Redis Desktop Manager | Redis / Tair 键值结构检视、TTL 排查与内存占用观测    |
| Apifox / Postman              | RESTful 接口契约管理、MCP 工具载荷验证与回归测试集合 |

### 容器、终端与线上可观测

| 工具名称            | 主要用途                                                |
| ------------------- | ------------------------------------------------------- |
| OrbStack / Docker   | 本地快速拉起 MySQL、Redis、RabbitMQ、ES 及隔离测试沙箱  |
| iTerm2 + zsh        | 远程 Linux 主机运维、日志流检索与评测流水线执行         |
| Arthas & SLS 控制台 | Java 线上方法耗时追踪、内存堆栈诊断与百万级设备日志检索 |
