经过 **3 年一线项目锤炼**，我的技术体系围绕 **AI 智能体（Agent）工程化** 与 **Java 分布式全栈开发** 展开——既能深入底层排查存储瓶颈与网络协议问题，也能构建从模型工具编排到交互界面的完整业务闭环。

---

## 核心技术领域

### AI 智能体与大模型应用工程

熟悉智能体领域核心架构范式，具备将大模型深度整合进高可靠传统企业系统的实战经验：

- **Agent Harness 与运行机制**：基于 ReAct 思想构建统一上下文（Context）、工具注册（MCP / Skill）与执行反馈循环，结合任务级沙箱实现动态 Python 脚本可控执行。
- **检索增强与工具调用**：熟练运用 Spring AI / Spring AI Alibaba 框架、RAG 知识检索与结构化工具协议打通内部业务服务。
- **质量评测与规则进化**：搭建离线分层门禁、黄金集/错题集回归（`pass^k`）与线上人工复核金标对账体系，推动业务规则可追溯自进化。

### 后端架构、存储与中间件

具备扎实的 Java 与 Python 编程功底及良好的代码规范，能够针对业务规模进行高可用微服务架构设计与性能调优：

- **微服务与业务编排**：熟练掌握 Spring Boot、Spring Cloud Alibaba、PandoraBoot 等主流框架，具备 DDD 领域驱动设计与 Flowable 工作流引擎编排经验。
- **数据库与检索调优**：深入理解 MySQL（InnoDB 存储引擎、事务隔离、复合索引优化及分库分表 TDDL），熟悉基于 Canal + ElasticSearch 的异构数据增量实时同步。
- **缓存、消息与网络通信**：熟练使用 Redis / Tair（五大数据结构、持久化及集群方案）与 RabbitMQ / MetaQ / Kafka（异步削峰、延迟交换机及消息可靠性保障）；掌握基于 Netty 的 TCP / UDP / MQTT 多协议物联网网关开发。

### 前端开发与线上运维保障

- **现代前端工程**：熟悉 Vue、React、Next.js 与 Tailwind CSS，具备企业级管理后台、数据可视化大屏及微信小程序独立开发能力。
- **Linux 与云原生运维**：熟悉 Linux 环境下的命令排障、JVM 内存分析与性能监控，结合 Docker、Kubernetes 与 SLS 日志服务保障生产环境稳定高可用。
