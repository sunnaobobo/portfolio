## 全职经历

### 深圳易宝软件有限公司

**AI 开发**（2025 年 8 月 - 至今）

驻场深度参与飞猪机票核心业务自动化与一体化投放平台研发，聚焦多格式航司优惠政策理解、工作流编排与智能体工程建设：

1. **机票政策解析 Agent Harness 从 0 到 1 建设**：主导整体架构、核心开发及上线迭代。设计基于 ReAct 的 Agent 运行机制，统一任务上下文、MCP 工具接口与执行反馈，集成文件读写、模板匹配、Python 脚本生成执行与 OSS 上传等能力，打通“文件解析—验价—投放上线”自动化链路。
2. **任务级沙箱与可控执行机制**：针对大模型动态生成脚本的不确定性，构建任务级独立工作区、权限约束与资源配额隔离，避免并发任务串扰或异常脚本影响核心服务。
3. **双轨质量评测与规则自进化闭环**：建立离线分层门禁与线上复核金标监控体系；构建“字段反馈—AI 冲突检测与候选生成—回归评测（`pass^3`）—版本化审核发布”规则闭环，支撑日均 **140+** 份政策文件自动解析（成功率 **100%**，准确率由 **76.4%** 提升至 **92.1%**，单文件耗时由 **2 小时** 缩短至 **5 分钟**；40 家航司规则建设周期由 **15 天** 压缩至 **3 天**）。
4. **机票投放一体化全链路改造**：引入 Flowable 编排全流程线上化节点，设计“正则提取 + Groovy 转换”平台化规则方案，采用航线分片增量计算与 `SXSSFWorkbook` 流式写盘解决笛卡尔积 OOM 问题，并通过 MetaQ 异步复用领域服务将平均投放时效由 **72 小时+** 缩短至 **3 小时** 以内。

### 泰安市东信智联信息科技有限公司

**全栈开发**（2023 年 7 月 - 2025 年 7 月）

参与城市级智慧停车、共享电单车调度及智慧园区等数字化平台全栈研发，贯通硬件协议接入、分布式后端微服务与小程序/管理端界面：

1. **核心平台微服务研发**：负责“泰山易行”设备网关、百万级日志采集分析系统与线上运维工单服务的迭代升级；参与“泰山易停 & 小停泊车”订单实时检索同步（Canal + ElasticSearch）、超时延迟队列处理（RabbitMQ）及基于 Spring AI + MCP + Qwen3 的智能停车助手建设。
2. **多端功能落地与部署**：负责“泰山易停 & 小停泊车”小程序升级、路内停车自动计费模块的设计开发以及测试环境持续集成部署。
3. **物联网协议标准制定**：与硬件研发部门协同论证公司硬件产品的通信协议选型（TCP / UDP / MQTT），主导编写设备接入协议规范文档。
4. **异构智能硬件集成**：基于 Netty 等网络框架完成车位相机、车位锁、地磁传感器、抓拍机、电单车中控及人脸识别消费机等多品类物联设备与业务系统的对接联调。
