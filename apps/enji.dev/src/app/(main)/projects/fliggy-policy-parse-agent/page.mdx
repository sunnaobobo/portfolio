## 业务背景与核心痛点

在飞猪自营机票业务中，各大航空公司会持续下发多格式、非标准化的机票优惠政策文档（涵盖复杂合并单元格表格、多 Sheet 矩阵及退改签补充说明）。

长期以来，业务高度依赖运营人员手工阅读拆解异构政策，并将其逐行换算转换为飞猪标准投放模板文件：

- **解析门槛高、耗时长**：不同航司排版差异悬殊，单份复杂政策人工拆解制表平均耗时近 **2 小时**。
- **投放滞后错失窗口**：人工排队处理导致优惠运价上线不及时，难以快速响应市场票价波动。
- **纯 Prompt 方案难以落地**：长表格直接拼入上下文极易触发截断漏行与数值换算幻觉，无法满足核心票务交易的准确性要求。

为此，我主导推动政策解析 Agent 能力从 0 到 1 建设，打通 **“文件解析—验价—投放上线”** 自动化链路，将运营人员从繁重的手工制表转向高效的结果复核。

## 核心职责与关键技术突破

### 1. 政策解析 Agent Harness 架构设计

负责整体架构设计、核心代码研发及多轮线上迭代。摒弃“让大模型直接口算输出全量表格”的脆弱做法，设计基于 **ReAct（Reasoning + Acting）** 的运行机制：

- 统一封装任务上下文、标准工具契约与结构化执行反馈；
- 集成源文件结构读取、标准投放模板选择、Python 解析脚本动态生成执行及结果文件 OSS 上传等工具；
- 由模型自主决策完成航司政策语义理解、编写并调试 Python 转换脚本，最终由确定性脚本将多格式原始文件转换为标准化投放 Excel。

```java {title:PolicyAgentHarness.java}
public ParseResult runHarness(PolicyParseTask task) {
  WorkspaceSession session = sandboxManager.allocate(task.getTaskId());
  try {
    AgentContext ctx = contextBuilder.build(task, session, ruleRegistry.loadActive(task.getAirlineCode()));
    while (!ctx.isCompleted() && ctx.stepCount() < MAX_STEPS) {
      ActionPlan plan = reactPlanner.nextStep(ctx);
      Observation obs = mcpExecutor.executeInWorkspace(session, plan);
      ctx.appendStep(plan, obs);
    }
    return qualityValidator.validateArtifact(session.getOutputExcel());
  } finally {
    sandboxManager.cleanup(session);
  }
}
```

### 2. 任务级工作区与可控沙箱执行机制

针对大语言模型动态生成 Python 脚本天然存在的不确定性，构建严密的执行隔离防线：

- **任务级数据隔离**：为每个并发任务挂载独立工作区目录，严格隔离输入源文件与中间产物，彻底杜绝高并发场景下的文件读写串扰。
- **脚本权限与模块白名单**：约束生成脚本仅允许调用受控的数据处理库与当前工作区路径，拦截外部网络请求及危险系统调用。
- **资源配额与超时熔断**：设置子进程内存上限与执行超时阈值，消除死循环或异常大内存脚本拖垮核心宿主服务的风险。

### 3. 离线门禁与线上金标双轨质量评测

建立覆盖研发迭代期与线上运行期的完整评测体系：

- **离线分层质量门禁**：每次模型切换、Prompt 调优或航司规则变更前，自动在基准集上校验产物可用性、政策类型识别、展开行数完整性与核心字段准确率，未达标自动阻断发布。
- **线上复核金标对账**：将运营人员在线上复核环节确认的最终投放结果沉淀为真实业务金标，持续监控各航司长周期准确率波动与运行稳定性。

### 4. 航司解析规则知识闭环自进化

为解决数十家航司格式持续演进带来的适配负担，构建 **“字段反馈—AI 冲突检测与候选生成—回归评测—审核发布”** 自进化闭环：

1. **字段级差异归因**：将线上人工复核修正拆解至具体字段级样本；
2. **冲突检测与人机协同分流**：自动检测新样本与存量航司规则是否存在语义冲突——无法复现或存在冲突的疑难字段转人工确认，其余清晰规律自动提炼生成候选规则；
3. **严格防退化门禁**：候选规则必须通过字段对照样本、历史黄金集与错题集回归测试，并满足 `pass^3`（连续三次独立执行全部命中）门禁验证，彻底阻断历史能力退化；
4. **版本化可回滚发布**：配合规则快照版本化管理，实现全流程变更可追溯与异常秒级回滚。
