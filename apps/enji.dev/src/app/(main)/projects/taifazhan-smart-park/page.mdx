## 项目背景与核心场景

**泰发展智慧园区（泰山发展投资智慧园区）** 是东信智联面向大型国企及企业园区综合数字化管理需求打造的一体化底座，旨在破解传统园区安防依赖人工巡检、能耗与物联设备难以统一管控、后勤办公与硬件系统彼此割裂等痛点。

平台围绕 **全园物联设备监控、智慧餐厨透明化管理、园区访客车位预约** 三大核心业务闭环展开：面向园区员工与来访客人提供一体化微信小程序（集成访客预约、园区导航、智能寻车、本月餐评、智慧餐厨与预约审批），同时面向园区物业与管理层构建 **3D 数字孪生实时监控大屏** 与自动化全域经营报表体系。

## 核心职责与技术亮点

### 1. 园区百级物联终端统一归集与监控大屏

负责园区物联设备统一管理模块的需求分析与核心功能设计：

- 基于 **Netty** 聚合园区内除门禁系统外的 **100+ 台多类型物联网终端设备**，建立统一心跳状态采集、离线异常告警与历史数据归集机制；
- 通过 **Socket.IO** 与 3D 数字孪生监控大屏实时联动展示设备运行态势，替代传统物业人工逐楼巡检，推动**园区日常设备运维效率提升 30%**。

### 2. 智慧餐厨管理与后厨透明化监管

负责对接智慧餐厨模块及员工身份核验链路，参与餐厨可视化大屏需求梳理与前后端联调：

- 打通园区微信小程序快捷登录、员工手机号绑定核验、**菜品互动投票（本月餐评）** 与 **人脸识别消费机** 就餐记录自动归集，稳定支撑园区 **1000+ 人次** 员工日常就餐登记与精准备餐，并支持一键生成导出周度/月度财务核算报表；
- 餐厨可视化大屏每日实时接入并分屏轮巡展示 **20 路后厨监控视频流**，落地“明厨亮灶”透明监管，显著提升园区食品安全管理与后厨精细化运营水平。

### 3. 高峰访客车位预约与停车流程优化

参与园区停车管理模块全流程梳理与功能落地，覆盖来访车辆登记、线上审批、车位预约及实时车位状态联动：

- 针对早高峰集中来访的并发预约峰值，基于 **Redis 原子锁 + 分时段配额扣减机制** 消除并发超卖与锁位冲突，稳定支撑高峰期**每小时 500+ 起车位预约请求**；
- 将预约审批单与现场车位终端及大屏态势动态联动，实现车辆离场或爽约超时后的车位自动释放回池，推动**园区整体车位使用率同比提升 20%**，并支持餐厨、停车、物联全域经营数据一键报表导出。
