## 项目背景与核心场景

**泰发展智慧园区** 面向大型企业园区的综合数字化管理需求打造，致力于打破传统园区各子系统烟囱林立的数据孤岛。

平台围绕 **智慧餐厨管理、园区停车预约管理、全园物联设备监控** 三大核心业务模块构建：既面向园区员工与来访客人提供便捷的微信小程序服务（如员工投票选菜、访客车位提前预约），又面向园区物业与管理层提供实时可视化监控大屏与自动化经营报表。

---

## 系统技术架构

项目采用轻量稳健的全栈实时架构：**Spring Boot + Redis + MySQL + Netty + Socket.IO**，前端联动园区小程序与管理监控大屏。

- **设备采集层**：基于 **Netty** 对接园区人脸识别消费机、环境传感及车位终端等多类型物联网硬件；
- **实时通信层**：通过 **Socket.IO** 将设备在线状态、车位余量与告警事件毫秒级推送到园区数字监控大屏；
- **业务与缓存层**：**Spring Boot + MySQL + Redis** 支撑高并发高峰期身份核验、投票计数、预约锁位与多维统计导出。

---

## 核心职责与技术亮点

### 1. 园区百级物联终端统一归集与监控大屏

负责园区物联设备统一管理模块的需求分析与核心功能设计：

- 聚合园区内除门禁系统外的 **100+ 台多类型物联网终端设备**，实现统一状态采集、异常离线告警与数据归集；
- 配合监控大屏实现设备运行态势实时可视化展示，替代传统人工逐楼巡检，推动**园区日常设备运维效率提升 30%**。

### 2. 智慧餐厨管理与后厨透明化监管

负责对接智慧餐厨模块及员工身份核验链路，参与餐厨可视化大屏需求梳理与联调：

- 打通园区小程序快捷登录、员工手机号绑定核验与**人脸识别消费机**就餐记录归集，稳定支撑园区 **1000+ 人次** 员工日常就餐登记、互动投票生成菜单及多维统计，支持自动生成并导出周度/月度就餐核算报表；
- 餐厨可视化大屏实时接入并轮巡展示每日 **20 路后厨监控视频流**，显著提升园区食品安全监管与后厨精细化管理水平。

### 3. 高峰访客车位预约与停车流程优化

参与园区停车管理模块全流程梳理与功能落地，覆盖来访车辆登记、车位预约及实时车位状态联动：

- 利用 Redis 原子锁与时段配额机制优化早高峰并发预约体验，系统稳定支撑来访高峰期**每小时 500+ 起车位预约请求**；
- 实现预约车辆与现场车位状态动态联动释放，使**园区整体车位使用率同比提升 20%**，并支持餐厨、停车、物联全域经营数据一键报表导出，为管理决策提供实时数据依据。
