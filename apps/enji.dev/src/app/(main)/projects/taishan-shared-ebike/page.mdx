## 项目背景与业务全貌

**泰山易行** 是服务泰安城区的城市级共享电单车绿色出行运营平台，在全市范围投放运营超过 **2000 辆** 共享电单车。

平台覆盖市民扫码骑行、电子围栏定点还车、多品牌车载智能中控接入、路面网格化运维调度以及政府监管平台实时数据对接等完整业务闭环。为应对多品牌硬件协议差异与复杂运维规则演进，系统核心采用 **领域驱动设计（DDD）** 架构构建。

---

## 技术架构与基础设施

项目运行于容器化云原生环境，核心技术栈涵盖：**Spring Cloud Alibaba + Nacos + Redis + MySQL + Netty + Kafka + Minio + ElasticSearch + 高德 SDK + SLS + OSS + Kubernetes**。

- **领域划分**：按 DDD 限界上下文清晰隔离设备连接网关域、车辆资产状态域、骑行计费订单域与路面运维工单域；
- **高吞吐管道**：利用 **Netty** 维护全量车载中控长连接心跳，借助 **Kafka** 削峰异步处理高频 GPS 轨迹流、状态变更与百万级设备日志。

---

## 核心职责与工程亮点

### 1. 多品牌中控设备网关维护与协议扩展

负责设备网关模块的持续优化以及小安中控通信协议的对接与增量能力开发：

- 通过防腐层编解码适配器屏蔽底层硬件指令差异，平台同时接入并支持**两大主流品牌、2000+ 辆共享电单车**的统一远程控车与平滑切换；
- 优化心跳保活、断线重连与指令应答机制，保障全平台车辆**日均在线率稳定超过 95%**。

### 2. 市级监管平台多维度数据实时同步

构建高可靠政企数据上报通道，实现与市级交通监管平台的实时对接：

- 对车辆实时位置、开关锁事件、电子围栏停放状态及订单流水进行标准化映射与失败重试补偿；
- **日均稳定同步车辆及订单监管数据超 5 万条**，确保平台合规运营与数据零漏报。

### 3. 每日百万级日志采集归集与排障提效

负责平台日志采集与运维支持模块建设：

- 整合 Kafka 与阿里云 SLS / ElasticSearch，支撑**每日百万级车载设备报文日志、现场运维记录及后台操作日志**的自动归集与多维检索分析；
- 针对扫码开锁异常、围栏定位漂移等高频现场问题建立链路追踪视图，使**线上运维问题定位时效提升 50%**。

### 4. 网格化运维工单流与批量部署工具

深入参与现场运维业务流与运营提效工具研发：

- 落地外勤人员**考勤打卡、车辆清洁、违停摆车、换电巡检**等多类型线上工单闭环，**日均线上运维任务处理量超 500 单**；
- 需求分析并实现**车辆二维码批量生成与归档工具**（结合 Minio / OSS），累计支撑生成车身二维码 **5 万+**，大幅加速新车批次投放与老旧车码更换效率。
