## 项目背景与业务全貌

**泰山易行** 是东信智联立足“**政府主导、国企运营**”城市绿色出行模式打造的泰安本土共享电单车运营与监管平台，在全市主城区投放并运营超过 **2000 辆** 融入泰山文化涂装元素的共享电单车。

平台贯通 **市民扫码骑行、高德电子围栏与“绿T区”定点还车、双品牌车载智能中控远程控车、路面网格化运维调度以及市级交通监管平台实时上报** 等完整业务闭环。面对多品牌硬件协议差异与复杂路面运维规则的持续演进，系统核心采用 **领域驱动设计（DDD）** 构建清晰的限界上下文边界。

## 核心职责与工程亮点

### 1. 多品牌中控设备网关维护与协议扩展

负责设备网关模块的持续演进，以及小安中控通信协议的对接与增量能力开发：

- 在 Netty 接入层基于 `LengthFieldBasedFrameDecoder` 与 CRC 校验构建帧定界防线，通过 **DDD 防腐层（ACL）编解码适配器** 屏蔽底层硬件指令差异，支撑**两大主流品牌、2000+ 辆共享电单车**的统一远程控车与平滑切换；
- 优化心跳保活、僵尸连接摘除、断线重连与 `msgId` 指令应答确认机制，保障全平台车辆**日均在线率稳定超过 95%**（详见网关架构文章：[基于 Netty 构建多协议物联网设备接入网关的实践与思考](/blog/netty-iot-gateway-architecture)）。

### 2. 市级监管平台多维度数据实时同步

构建高可靠政企数据上报通道，实现与市级共享助力车监管平台的实时对接：

- 对“五码合一”车辆备案、实时 GPS 轨迹、开关锁事件、电子围栏停放状态及订单流水进行标准化字段映射、加密签名与失败指数退避补偿；
- **日均稳定同步车辆及订单监管数据超 5 万条**，确保合规运营与数据零漏报，助力“泰山易行”在城市运营商动态考核中长期名列前茅。

### 3. 每日百万级日志采集归集与排障提效

负责平台日志采集管道与线上运维排障能力建设：

- 整合 **Kafka + 阿里云 SLS + ElasticSearch**，支撑**每日百万级车载设备原始报文、外勤现场记录及后台运维操作日志**的自动归集与多维全文检索；
- 围绕扫码开锁超时、电子围栏定位漂移等高频现场问题建立按车辆号与订单号串联的链路追踪视图，使**线上运维问题定位时效提升 50%**。

### 4. 网格化运维工单流与车身二维码批量工具

深入参与一线现场运维业务流与运营提效工具研发：

- 落地外勤人员**考勤打卡、车辆清洁消杀、违停摆车、换电巡检**等多类型线上工单闭环，**日均线上运维任务处理量超 500 单**；
- 独立完成**车身二维码批量生成与归档工具**的需求分析与开发（结合 **Minio / 阿里云 OSS**），累计支撑生成并归档车身二维码 **5 万+**，大幅压缩新车批次投放与磨损车码替换周期。
