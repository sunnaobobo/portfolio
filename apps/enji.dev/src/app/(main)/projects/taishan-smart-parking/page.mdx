## 平台定位与业务规模

**泰山易停 & 小停泊车** 是东信智联面向泰安市城市级停车业务数字化转型打造的综合智慧停车管理平台，以“**一张网、一平台、一张图**”为建设目标，打通静态交通供给侧与市民出行服务侧。

平台覆盖 **路外停车场管理、路内泊位停车、新能源汽车充电与电动自行车充电** 四大业务子系统，同步联动自主研发的 **智芯翼 `DX-EPA100` 智慧停车边缘计算终端** 与 **“易停巡检”** 运维小程序，为车主提供一键找车位、无感支付（微信 / 支付宝 / ETC）、商户停车优惠券与长租车位管理等全链路能力，全平台通过**等保三级**安全合规测评。

## 核心职责与技术亮点

### 1. 基于 Canal + Binlog 的订单实时同步与统一检索

负责停车订单数据同步与检索业务的需求分析及架构落地，并对多子系统订单查询接口进行业务梳理与收敛统一：

- 采用 **Canal 伪装 Slave 订阅 MySQL Row 模式 Binlog + 按订单号哈希路由的分片线程池（Striped Executor）** 捕获增量变更并微批 Bulk 写入 ElasticSearch，在对核心抬杆交易零侵入的前提下严格保证同一笔订单变更的局部有序；
- 以唯一单号作为文档 `_id` 并结合外部版本控制保障重放幂等，辅以低频定时对账任务兜底；收敛路外停车、路内泊位及充换电多类型订单查询门面，显著降低千万级数据下多条件组合筛选延迟（详见实践笔记：[基于 Canal 与 Binlog 的高并发订单实时检索同步实践](/blog/mysql-to-elasticsearch-realtime-sync)）。

### 2. 基于 Spring AI 与 MCP 的智能停车助手

参与智能停车助手模块的需求分析与全栈实现，响应平台向“AI + 静态交通”演进的业务需求：

- 基于 **Spring AI** 框架与 **MCP（Model Context Protocol）** 标准协议集成 **Qwen3 大模型**，打通自然语言意图识别与后端实时业务数据；
- 将实时余位查询、车场营收统计、周边空闲车场推荐及导航路线规划封装为受控工具接口，避免大模型幻觉编造车位信息，支持车主与运营人员一句话完成高频查询。

### 3. Netty 多协议设备接入网关与路内自动计费

深度参与公司硬件通信协议选型与设备接入流程规范编写，主导 **路内停车子系统** 业务流程设计与全栈功能开发（含小程序端升级与测试环境持续部署）：

- 使用 **Netty** 构建高并发多协议接入层，原生支持 **TCP、UDP、MQTT** 三类通信协议并存，单平台稳定承载数千台异构品牌的高位/低位车位相机、无线地磁、智能车位锁、充电桩以及 `DX-EPA100` 边缘计算终端；
- 路内停车子系统实时消费高位/低位车位相机状态流，打通“入位自动识别—分时段阶梯计费—离场无感扣费—异常欠费追缴”全自动闭环（详见网关复盘：[基于 Netty 构建多协议物联网设备接入网关的实践与思考](/blog/netty-iot-gateway-architecture)）。

### 4. 基于 RabbitMQ 延迟交换机的超时治理

参与订单支付超时处理、优惠券预占释放等核心交易异常流的设计优化：

- 引入 **RabbitMQ 延迟交换机（Delayed Message Exchange）** 替代传统高负载定时轮询扫表；
- 精准触发临时锁单未付自动释放、优惠券额度回滚及离场欠费补缴提醒，显著削减高峰期数据库无效扫描开销并改善车主缴费体验。
