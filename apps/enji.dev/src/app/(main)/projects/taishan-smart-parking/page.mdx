## 平台定位与业务规模

**泰山易停 & 小停泊车** 是面向泰安市城市级停车业务数字化转型打造的综合智慧停车管理平台。

平台涵盖 **路外停车场管理、路内泊位停车、新能源汽车充电与电动自行车充电** 四大业务子系统，统一支撑车场运营、计费结算、异构硬件接入、车主小程序服务及经营数据分析，助力城市静态交通治理：

- 累计接入城市各类停车场 **200 余家**；
- 平台注册车主用户突破 **200 万**；
- 日均处理停车与充电订单约 **5 万笔**。

---

## 分布式全栈技术架构

系统采用微服务与异构存储架构：**Spring Cloud Alibaba + Nacos + Redis + RabbitMQ + Netty + MySQL + ElasticSearch + InfluxDB + WebSocket**，并在智能化升级中引入 **Spring AI + MCP + Qwen3**。

| 模块维度       | 核心选型与工程作用                                                    |
| -------------- | --------------------------------------------------------------------- |
| 微服务治理     | Spring Cloud Alibaba + Nacos 实现多子系统服务注册发现与动态配置管理   |
| 交易与检索存储 | MySQL 承载核心计费订单事务，Canal + ElasticSearch 支撑多维毫秒级检索  |
| 时序与实时推送 | InfluxDB 存储设备运行指标，WebSocket 向管理端与小程序实时推送车位变更 |
| 物联与异步通信 | Netty 构建多协议硬件网关，RabbitMQ 延迟交换机驱动超时订单自动闭环     |

## 核心职责与技术亮点

### 1. 基于 Canal + Binlog 的订单实时同步与统一检索

负责停车订单数据同步与检索业务的需求分析及架构落地，并对多子系统订单查询接口进行业务梳理与收敛统一：

- 采用**分片线程池 + Canal 监听 MySQL Binlog** 方案捕获增量变更并实时同步至 ElasticSearch，在对交易主链路零侵入的前提下保障 MySQL 与 ES 之间的数据一致性；
- 统一路外停车、路内泊位及充换电多类型订单查询门面，显著降低多条件组合筛选延迟。

### 2. 基于 Spring AI 与 MCP 的智能停车助手

参与智能停车助手模块的需求分析与全栈实现：

- 基于 **Spring AI** 框架与 **MCP（Model Context Protocol）** 标准协议集成 **Qwen3 大模型**；
- 将实时余位查询、车场营收统计、周边车场推荐及导航路线规划封装为受控工具接口，支持车主与运营人员通过自然语言完成高频业务问答。

### 3. Netty 多协议设备接入网关与路内自动计费

深度参与物联网设备统一接入流程梳理，主导**路内停车子系统**业务流程设计与全栈功能开发（含小程序端升级与测试环境部署）：

- 使用 **Netty** 构建高并发多协议接入层，原生支持 **TCP、UDP、MQTT** 等通信协议，单平台可同时稳定承载数千台不同品牌、不同类型的车位相机、地磁传感器、智能车位锁及充电桩硬件；
- 路内停车子系统基于高位/低位车位相机状态流实现入位自动识别、分时段自动计费与离场无感结算。

### 4. 基于 RabbitMQ 延迟交换机的超时治理

参与订单支付超时处理等核心交易异常流的设计优化：

- 引入 **RabbitMQ 延迟交换机（Delayed Message Exchange）** 替代传统轮询扫表，精准处理临时锁单未付、优惠券预占释放及超时补缴提醒，大幅降低数据库无效扫描负载并改善车主支付体验。
